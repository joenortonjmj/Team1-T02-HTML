### Assignment Requirements

For this assignment, Team 1 implemented requirements from **Team 3 (Forms)** and **Team 5 (Tables)**.

### Team 3 - Forms and Inputs

✅ `<form>` - Dragon adoption application form  
✅ `<input>` - Text inputs for name, email, phone number  
✅ `<textarea>` - Special requests and comments field  
✅ `<button>` - Submit and reset buttons  
✅ `<select>` - Multiple dropdowns (dragon size, experience level, housing type)  
✅ `<option>` - Options within select dropdowns  
✅ `<label>` - Labels for all form inputs  
✅ `<fieldset>` - Three fieldsets grouping related form fields  
✅ `<legend>` - Legends for each fieldset  

### Team 5 - Tables and Interactivity

✅ `<table>` - Dragon inventory table  
✅ `<tr>` - Table rows  
✅ `<td>` - Table data cells  
✅ `<th>` - Table header cells  
✅ `<thead>` - Table header section  
✅ `<tbody>` - Table body section  
✅ `<tfoot>` - Table footer section  
✅ `<caption>` - Table caption  
✅ `<col>` - Column styling  
✅ `<colgroup>` - Column group  
✅ `<details>` - Five expandable care guide sections  
✅ `<summary>` - Summary text for each details element  
✅ `<dialog>` - Modal dialog showing dragon specifications  

### Website Concept

**Adopt-a-Dragon Interest Form** - A dragon adoption website featuring:
- Available dragons displayed in a structured table
- Application form with contact info, preferences, and special requests
- Expandable dragon care guide sections
- Dialog popup showing detailed dragon specifications
